# 시뮬레이션 환경 구축

본 연구는 SUMO 기반 교통 시뮬레이션 환경에서 응급차 우선신호 적용 전후를 비교한다. 대상 공간은 중부소방서에서 주요 목적지로 이동하는 도심 corridor이며, 동일한 도로망과 교통수요 조건에서 일반 신호 운영 시나리오와 우선신호 시나리오를 나누어 실행한다.

## 1. 도로

도로망은 실제 도심 도로를 SUMO `net.xml` 형식으로 변환해 구성했다. 반복 실험 비용을 줄이기 위해 전체 지도가 아니라 중부소방서, 서울역 방향 축, 검증 목적지를 포함하는 축소 네트워크를 사용했다. 차량 통행이 가능한 edge, 차로 연결, 교차로 접근 방향을 유지해 응급차 경로 생성과 교차로별 신호 제어가 가능하도록 했다.

## 2. 신호체계

신호체계는 SUMO의 TLS 정보를 기준으로 구축했다. 각 응급차 경로에서 통과하는 신호 교차로를 식별하고, 진입 edge와 진출 edge를 매핑해 해당 movement가 어떤 signal phase에서 통과 가능한지 확인했다. 기준 시나리오는 기존 신호 운영을 유지하고, 우선신호 시나리오는 응급차 접근 시 green 확보, 통과 후 green 정리, 회복시간을 적용한다.

## 3. 교통량

교통량은 첨두시간 도심 혼잡을 재현하기 위해 배경 차량 route 파일로 주입했다. 시뮬레이션 시작 직후의 불안정한 상태를 피하기 위해 warm-up 이후 응급차를 출발시키며, 같은 도로망과 같은 배경수요 조건에서 시나리오를 비교한다. 평가지표는 응급차 지연시간, 일반차 평균지연시간, 신호 개입 부담을 함께 사용한다.

## 4. 시각화

시각화는 지도 기반 경로 개요, 단일 응급차 경로 상세, 시나리오별 지연 비교 그래프로 구성한다. 지도 이미지는 시뮬레이션 범위와 사고위치/목적지를 보여주고, 애니메이션 캡처는 우선신호가 실제로 어느 구간에서 개입하는지 설명하는 데 사용한다. 결과 그래프는 S1과 S2의 응급차 지연 및 일반차 지연 차이를 짧게 보여주는 용도로 쓴다.
