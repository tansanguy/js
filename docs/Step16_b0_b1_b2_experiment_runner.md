# Step 16 B00/B0/B2 Experiment Runner

## Purpose

`02_simulation/run_b0_b1_b2_experiment.py` is the single entrypoint for final B00/B0/B2 route-level experiments.

Earlier Step9-Step15 scripts are setup, audit, smoke, and diagnostic tools. Do not use them as the final experiment command.

## Modes

- `B00`: emergency-only free-flow baseline. No background demand, no signal control.
- `B0`: peak background demand plus emergency vehicle. No signal control.
- `B2`: same peak background demand as B0, with corridor priority control from `configs/b2_parameter_sets.csv`.

`B1` is not generated by this runner.

## Pipelines

Parameter input simulation:

```bash
python3 02_simulation/run_b0_b1_b2_experiment.py \
  --manifest configs/final_experiment_manifest.json \
  --pipeline parameter_input_sim \
  --modes B00 B0 B2 \
  --repeats 1 \
  --workers 1
```

Final effect validation:

```bash
python3 02_simulation/run_b0_b1_b2_experiment.py \
  --manifest configs/final_experiment_manifest.json \
  --pipeline final_effect_validation_sim \
  --modes B00 B0 B2 \
  --repeats 5 \
  --workers 4
```

## Outputs

Each pipeline writes one CSV:

- `results/metrics/parameter_input_sim.csv`
- `results/metrics/final_effect_validation_sim.csv`

Raw SUMO outputs are under:

- `runs/final/{pipeline}/{mode}/{parameter_id}/{repeat_id}/{route_id}/`

## Metrics

- `A_delay_sec`: B0/B2 emergency travel time minus same route/repeat B00 emergency travel time. B00 is `0.00`.
- `N_delay_sec`: mainstream general-vehicle delay average from TraCI vehicle time on corridor edges versus edge free-flow time.
- `T_recovery_sec`: B2 maximum controlled-signal restore time after emergency passage. B00/B0 are `0.00`.
- `score_sec`: equal-weight sum of the three metrics.

All `_sec` values are seconds rounded to two decimals.

## Guardrails

The runner blocks unsafe final-style execution when:

- manifest paths are missing
- background route does not contain `scale_0p15`
- `ER_ACC_013` appears in `b0_valid_18`
- B2 parameter CSV is empty or lacks required columns
- `--output-prefix experiment` is used without `--legacy-output-names`

Use `--allow-nonfinal-background` only for explicit diagnostics, not final comparison.
