# Experiment Design

## 연구 배경 요약

응급차량 출동 시 교차로 지체는 현장 도착시간에 직접 영향을 준다. 본 프로젝트는 SUMO 기반 시뮬레이션으로 긴급차량 우선신호 제어 방식의 효과와 일반차량 영향도를 비교한다.

## 분석 대상

- 공간 범위: 중부소방서 권역, 서울역 포함 분석권역.
- 시간대: 07~09 중 대표 10분.
- 사고지점: SUMO에서 도달 가능한 edge 중 고정 시나리오로 선정.
- 소방차: 1대, 시뮬레이션 1회당 출동 1회.
- 경로: 사고지점별 다익스트라 경로를 사전에 생성하고 재사용.

## 비교군

- `B0 baseline`: 일반신호.
- `B1 independent_priority`: 기존 독립 우선신호.
- `B2 corridor_priority`: 제안 구간협조 우선신호.

## 출력 지표

- 응급차 통행시간
- 응급차 정지 횟수
- 일반차 평균 지체시간
- 일반차 평균 대기시간
- 샛길 최대 대기열
- 신호 회복시간
- 신호조작 횟수

Score는 추후 결과 분석 단계에서 계산한다. Bayesian Optimization은 이 코드베이스 내부에서 수행하지 않고, 결과 CSV를 외부 최적화 파트에 넘긴다.
