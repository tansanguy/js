# Step 5 reduced map 확정

이 단계는 최종 실험에 사용할 reduced network를 확정한 기록이다.

## 결정

최종 active net:

```text
data_prepared/net/jungbu_ellipse_passenger.net.xml
```

## 이유

- 중부소방서와 서울역 방향 corridor를 포함한다.
- full map보다 실행 부담이 낮다.
- emergency route와 background demand 실험을 반복 실행하기에 적합하다.

full map 산출물은 보존하지만 최종 실험 입력에서는 제외한다.
