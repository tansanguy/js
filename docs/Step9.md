# Step 9 background demand 점검

이 단계는 일반차 배경 수요와 edge 사용량을 점검한 기록이다.

## 목적

- 첨두시간 배경 수요가 active net에서 실행 가능한지 확인한다.
- planned edge usage와 actual edge usage를 비교한다.
- 지나친 teleport나 route error를 확인한다.

## 최종 배경 수요

```text
data_prepared/demand/background_routes_am_imputed_a17_a19_scale_0p15.rou.xml
```

이 파일은 B0/B2에서 동일하게 사용한다. B00에서는 사용하지 않는다.
